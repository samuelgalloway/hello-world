Voice Browser Settings

Stored locally in this browser profile (chrome.storage.local) and only ever sent to api.typesafe.ai from the extension's background service worker. Never checked into any repo.
Used only as a fallback to compose the exact text for a "type" action when it isn't a clean literal (e.g. "tell them the meeting moved to 3pm" rather than a quoted value). TypeSafe's Jev model returns judgments, not generated text, so this covers the cases it structurally can't. Leave blank to skip this fallback -- typed values will just use the best-effort literal extracted from what you said.

Site shortcuts

Named shortcuts let you say things like "open the permissions dashboard" instead of a full URL. When your instruction doesn't match a saved shortcut, the extension falls back to treating it as a URL or a web search.
